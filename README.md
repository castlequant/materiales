# Materiales de CastleQuant

Este repositorio reúne el material abierto de CastleQuant: cuadernos, datos y guías de los en vivos y de las rutas de aprendizaje. Todo está pensado para que lo abras, lo ejecutes y lo modifiques tú.

## Estructura

```text
en-vivos/   un folder por clase en vivo, con nombre AAAA-MM-DD-tema
rutas/      material de apoyo por ruta de aprendizaje (quant-start, quant-math...)
temas/      material agrupado por tema, sin importar la clase o la ruta
gratis/     material abierto para cualquier cuenta
```

Cada folder tiene su propio README que dice qué va ahí.

## Cómo abrir un cuaderno en Google Colab

1. Abre el cuaderno en GitHub y copia su ruta dentro del repositorio.
2. Pega la ruta al final de este enlace: `https://colab.research.google.com/github/castlequant/materiales/blob/main/<ruta>`.
3. Para los cuadernos de este repositorio, usa el botón «Abrir en Colab» de la tabla.
4. Los CSV de cada folder están en el mismo lugar que el cuaderno. Sube los archivos que pida a la sesión de Colab o cárgalos desde su enlace «Raw» de GitHub.

Los cuadernos se guardan sin resultados para que el repositorio pese poco. Ejecuta las celdas en orden para generarlos.
